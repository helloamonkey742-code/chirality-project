Unit droplet_range.  Model study on SIMULATED drops, not data.  The D2 rule of journals/droplet_prereg.md Section 2 is
frozen and is not changed here; amendments below are proposals only.  Disclosed before this file: one timing run
(scratchpad time1.py) that ran droplet_sim2.truths() once and run_cell on 300 runs of "probit s=0.15" to size the
compute; it printed no verdict shares.

SETUP (both parts)
- Protocol: droplet_sim2.protocol (pilot ladder 0.25-16 uL, 20 drops; 8 levels 0.2-1.6 x V0_pilot, ratio exp(Q) = 1.346,
  25 drops per level; extension rule, cap 2 levels; 128 controls, 64 one-seed + 64 two-seed).  droplet_range_common.protocol2
  reproduces it exactly for the same seed when misreads are symmetric (checked in its self-check).
- Rules, all with the per-run measured misread e_hat = (k + 0.5)/129 unless said:
  A   = droplet_sim2 rule as first frozen: fixed 3% term, c* = -1.61, no control cap (what droplet_sim2.log used).
  B   = the rule now in prereg Section 2: e_hat in both fits, c* = -2.21, NOT SCORABLE if k/128 > 0.10 (prereg Section 2 item 1).
  AM1 = proposal 1: B plus a plateau h in the STEP family only.
  AM2 = proposal 2: B plus a plateau h in BOTH families.
  Plateau: P = h + (1 - h) F(.) for h in {0.05,0.1,0.15,0.2,0.25,0.3,0.35,0.4,0.5}, fitted in addition to the frozen
  h = 0 grids (so every amended likelihood is >= the frozen one), on coarser mu and Vc grids (0.1 and 0.04 in ln units).
  c*_AM1 and c*_AM2 are set the way c*_B was (lowest 5th percentile of L over counting cells x conditions, runs that are
  scorable, range >= 0.4 and z <= 1.645, at least 50 such runs) on a CALIBRATION seed, from the 87 counting cells plus 27
  counting-with-floor cells; then frozen; every number below is on a fresh EVALUATION seed.
- Truth for the plateau map: P = h + (1 - h) Phi(-ln(V/3.1 uL)/s), no empty drops.  "main" condition = pipette CV 0.05,
  true symmetric misread 0.03.  Share = fraction of runs given that verdict.  Other conditions: (CV 0.05, 0), (0.05, 0.06), (0.15, 0.03).
- Calibration conditions: CV {0.05, 0.15} x misread {0, 0.03, 0.06, 0.10}; 600 runs per cell-condition; evaluation 500.
  Plateau map: 1000 runs per cell-condition.  Part (b): 500 runs per cell-condition (300 for the null check).

PART (a)  PLATEAU BLIND SPOT  (h in {0,0.1,0.2,0.25,0.3,0.4,0.5} x s in {0.05,0.1,0.15,0.3})
P1  Replication.  Rule A, main condition, h = 0.3, s = 0.15: STEP share in [0.02, 0.09] (droplet_sim2.log gives 0.05).
P2  Rule B, main condition, h = 0: STEP >= 0.95 at s = 0.05, 0.1 and 0.15.
P3  The blind spot persists under B.  Rule B, h = 0.3, s = 0.05, 0.1, 0.15: STEP <= 0.15 in each of the four conditions.
P4  Monotone fall.  Rule B, main, s = 0.1 and 0.15: going h = 0, 0.1, 0.2, 0.25, 0.3, 0.4, 0.5, STEP never rises by more than 0.03 between neighbours.
P5  Where it fails.  Rule B, main, s = 0.1 and 0.15: STEP(h = 0.1) >= 0.80, and 0.10 <= STEP(h = 0.2) <= 0.80.
P6  High plateau (two nuclei cap, h = 0.5).  Rule B, main, s = 0.1 and 0.15: STEP <= 0.15 (verdict is SMOOTH or NOT SCORABLE).
P7  Ceiling below 1 (polycrystalline or two-nuclei small drops), P = c Phi(-ln(V/3.1)/s).  Rule B, main, c = 0.9, s = 0.1 and 0.15: STEP >= 0.80.
P8  One-way detection miss (a mixed drop read single with probability m, never the reverse; s = 0.1; controls then read wrong at m/2
    on average).  Rule B, main: m = 0.06 and 0.12: STEP >= 0.85; m = 0.20: NOT SCORABLE share >= 0.30 (control cap).
P9  Informative exclusion of unreadable mixed drops (share u of mixed drops dropped, P_read = P/(P + (1-P)(1-u)), s = 0.15).
    Rule B, main, u = 0.5, 0.8, 0.9: STEP >= 0.90 each.
P10 Replication of c*.  Rule B recalibrated with this script's conditions on the 87 counting cells: c*_B0 in [-2.9, -1.7] (frozen: -2.21).
P11 c*_AM2 in [-5.0, -1.5].
P12 False STEP of AM2.  Evaluation seed, every condition: highest STEP share over (87 counting cells, 27 exclusion curves of
    exclusion_bak.py, 27 counting-with-floor cells) <= 0.07.
P13 B is not fooled by floors.  Rule B (c* = -2.21), the 27 counting-with-floor cells, every condition: highest STEP share <= 0.07.
P14 AM2 sees plateaus.  Main, h = 0.1, 0.2, 0.3, s = 0.1 and 0.15: AM2 STEP >= 0.80 in each.
P15 AM2 keeps pure steps.  Main, h = 0: AM2 STEP >= 0.95 at s = 0.05, 0.1, 0.15, and at s = 0.3 AM2 STEP >= (rule B STEP) - 0.15.
P16 Floor in COUNT buys power.  Main, h = 0, s = 0.3: STEP(AM2) - STEP(AM1) >= 0.05.  If this fails, AM1 (the smaller change) is preferred.

DECISION RULES
(a) The blind spot "matters" if rule B STEP(h = 0.2, s = 0.1) < 0.80 in the main condition.  If it matters AND AM2 holds P12, P14 and P15,
    the notes file proposes AM2 (AM1 instead if P16 fails and AM1 also meets P12, P14, P15), marked not applied.  If it matters but AM2 breaks one
    of P12, P14, P15, the notes propose a limit sentence only.  If it does not matter, no amendment is proposed.
(b) Recommended design for a span = the lowest-cost design among base, ext4, K10, K12 whose lowest STEP share over the span grid is >= 0.95
    in (CV 0.05, misread 0.03) and (CV 0.05, misread 0.06) at s = 0.1 and 0.15, and whose highest null STEP share at the frozen c* is <= 0.07.
    If none qualifies, the notes give the widest span a design does reach.
Failed predictions are reported as failed; this file is not edited after the first results run (a v2 file would be named
droplet_range_predictions_v2.txt and the scripts would say so).
