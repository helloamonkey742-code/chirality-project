Model     rna_copying.py (LO-type: n = 3, c = 0.5, w = 0.02, h from k4, kobs = 7.35 /h, M_REF = 24 mM, T_COLD = 1 h, T_IN = 3 uM),
          r in {0.40, 0.56, 0.98}; feed m_in in {5, 20, 200} mM, 20 mM = main. Contrast row: r = 1.141 (arm_g_rates.log:44).
Settings  scorecard.SETTINGS: pond 1e-2 M, 100 yr; lake 1e-4 M, 1e4 yr; ocean 1e-6 M, 1e8 yr; N = c V 1000 N_A; e_need = scorecard.spec().
          Noise as in rna_seed_scan.py: stationary linear-noise (discrete Lyapunov) readout variance s^2, Omega = N_setting / m_in per mM.
Unit      the model has no free primer pool. The primer-template duplex T is the unit; "seeded templates/primers" = excess in T_D vs T_L.

(a) FEED SEED   excess ee0 in the monomer feed, m_in (1 +/- ee0)/2. Letters are taken from rna_seed_scan.log (not re-derived); this script
          only reproduces the gains/|lam| it needs and adds a setting-consistent supplement (block S).
"followed" (WEAK, = rna_seed_scan.py): Delta = readout excess / s >= 2, readout = steady product excess (D-L)/(D+L) of full-length copies.
          e_min = smallest seed followed = 2 s / |gain|. Letter: Y if e_min <= e_need in all three settings, P in some, N in none.
          Judged here: it is a signal-to-noise test of a bounded, monostable response to a continuously supplied excess. It is sound
          as "the readout tracks the feed", NOT as "the system selects a homochiral state"; the e_need it is compared with comes from
          a bifurcation ramp (inherit.py), a different decision problem. The letters are reported with that caveat.

(b) TEMPLATE SEED   racemic feed (e = 0, racemic template feed T_in/2 each), state at the racemic fixed point z* = [T*, T*, m*, m*],
          then T_D = T*(1 + ee0), T_L = T*(1 - ee0) at t = 0. Linear regime ee0 << 1 (checked against the nonlinear map).
  ee_T(t)   = (T_D - T_L)/(T_D + T_L) = x(t)/(sqrt(2) T*), [x, y](t) = Jd^t [x0, 0], x0 = sqrt(2) T* ee0 (Jd = difference-mode block).
  rho(t)    = ee_T(t)/ee0 = x(t)/x0.
  cycle     one model cycle = cold copying phase (1 h, assumed) + hot phase. Cycle length L is NOT measured: bracket L = 1 h and L = 24 h.
            n_cyc(tau) = tau / L, tau in hours = tau[s] / 3600.
  outcome   at tau: GROWN if max_{0 < t <= tau} rho(t) > 1 (+1e-9);  KEPT if rho(tau) >= 0.5;  otherwise LOST.
  "followed" (WEAK, as in (a)): Delta_T = |g_T(tau)| ee0 / s >= 2, g_T(t) = readout(t)/ee0 = rho_vec . Jd^t [x0, 0] / ee0 (rho_vec = readout slope
            wrt [x, y], as rna_seed_scan.linear). e_min^T(tau) = 2 s / |g_T(tau)| (envelope for a complex pair). "none" if > 1.
  "followed" (STRONG): weak AND outcome in {KEPT, GROWN}.
  letter    Y if e_min^T <= e_need in all three settings, P in some, N in none. Given for weak and strong, per r and per L.
  Why both: the weak rule counts a seed that has decayed by e^-19 as "followed" if the remnant is still above counting noise; that is
            tracking a vanishing signal, not inheritance. The strong rule is what the scorecard comment ("works from <= ~1% ee") needs.

(c) POISONING OBJECTION (paraphrased: a racemic monomer pool poisons copying, so copying only matters after symmetry breaking).
  Inside the model "poisoning" = wrong-hand monomer (rate ratio r) terminating strands, plus halving the right-hand concentration.
  per attempt   S = p^n P(N >= n), p = m_R/(m_R + r m_W), mu = A (m_R + r m_W)/M_REF. Racemic pool: m_R = m_W = m. Pure pool: all
                monomer one hand, same TOTAL (2m): S_pure = P(Poisson(A 2m/M_REF) >= n). "Same right-hand level": S(m, m) vs S(m, 0).
  reactor       steady state of rna_copying.step with feed excess e = 0 (racemic) and e = 1 (pure), same total feed m_in.
                Q = T*/(T_in/2) (templates relative to the no-copying level; Q = 1 means copying does nothing).
                Y = full-length copies per cycle summed over hands = c (T_D S_D + T_L S_L). Y_rac/Y_pure at the same total feed.
  onset         feed at which copying just keeps up with washout, c S = w/(1-w) (rna_copying.onset for the racemic pool; same formula with
                p = 1, one hand, for the pure pool: m_in = m (1 - (1-w)(1-h))/w).
  survives      an inherited FEED excess "survives" the racemic pool if the steady product excess is >= 2 x the feed excess (gain >= 2)
                (a gain >= 2 means the poisoned pool still reports and enlarges the excess).
Verdict rule for (c): V1 poisoning real = racemic onset >= 1.8 x pure onset for all three r. V2 copying not blocked = racemic Q >= 50 at
  20 mM for all three r. V3 feed excess survives = gain >= 2 in all 9 cells (r x feed). V1&V2&V3 -> "partly true: costs a factor ~2-3 in
  feed and about half the yield, does not block copying and does not erase a feed excess". Otherwise reported as the numbers say.
