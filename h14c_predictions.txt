QUESTION (open item 14 / H14, journals/ija_draft.md:252; E86 :187; Section 2.3 :479; :790; sibling analysis h14_eddy.log:81-171):
h14b_advect.py measured the slowdown S of wall clearing under explicit eddies at ONE molecular ratio, D_mol/D_eff = 1/8:
S50 = 2.0 (l/w 3.6), 6.3 (l/w 10), and only "S50 > 8" (censored) at l/w 30, where the first kick came 77 time units AFTER
freeze-out (Tk = 277 against a sweep of 200). Two things were left open. (1) At l/w 30 the flow had not acted before freeze-out,
so the 8 censored units say nothing about the eddy slowdown. (2) The real ratio D_mol/D_eff is ~1e-9, and the molecular
reference (no flow) scales as D_eff/D_mol (h14b J 9.33, K 13.36 at 1/8). If S grows with the ratio, h14b's covered /
not-covered verdicts do not carry to real worlds. h14c measures S at D_mol/D_eff = 1/32 and 1/64 at l/w 3.6 and 10, at 1/32 at
l/w 30 with 10 kicks across the sweep, and re-measures 1/8 in the same code.

DEFINITIONS
  Model, S, S50, S80, S_half, t17, Kaplan-Meier, bootstrap (resample runs, 2000x): exactly as h14b_advect_predictions.txt
  (h14b_advect.py imported, not edited). Differences, all fixed here:
  - D_mol = 1, h = 1 for all D_eff, so the molecular wall is as resolved as in h14b B/G/I: sqrt(D_mol/k) = 1 cell (tanh
    half-width sqrt(2) = 1.41 cells). The effective wall sqrt(D_eff/k) is 2.83 / 5.66 / 8.0 cells at D_eff = 8 / 32 / 64.
    One h = 0.5 partner (V32_3.6h) gives the molecular wall 2 cells (tanh half-width 2.83) and tests the resolution at 1/32.
    Euler: D dt/h^2 = 0.2 (h = 1, dt = 0.2) or 0.2 (h = 0.5, dt = 0.05), limit 0.25.
  - D_eff in {8, 32, 64}; flow = the h14b/advect2d kicked random-phase alternating sine shear (cubic Lagrange kick) with
    kappa = A/l = 1.47 (KAPPA2 = 2.159), n = 1, box L = round(2 pi (l/w) sqrt(D_eff)), eddy l = L/(2 pi),
    Tk = round(KAPPA2 l^2 / (8 (D_eff - D_mol)) / 0.2) 0.2, A = sqrt(8 (D_eff - D_mol) Tk), so D_eddy = A^2/(8 Tk) = D_eff - D_mol.
  - t17(L, D_eff) = (L/5.5)^2 / D_eff = 1.305 (l/w)^2 / k, the same 16.9 / 130 / 1174 time units for l/w 3.6 / 10 / 30 at
    every D_eff (h14b_advect.py:76 hard-codes D_eff = 8; h14c uses a Stat subclass with the case's own D_eff).
  - gamma per case (h14b used 0.01 for all, which gave a pre-freeze-out coarsening time 1/gamma of 5.9 / 0.77 / 0.085 t17 at
    l/w 3.6 / 10 / 30, a confound with l/w): gamma = min(0.01, round(1/(5 Tk), 4)), i.e. 5 kicks between lam = 0 and the end of
    the sweep (10 kicks across the whole sweep) for the cells with Tk > 20; pre-time 1.05-1.18 t17 for every l/w 10 and 30 cell.
    The bias g is taken at the ACTUAL gamma: g = K.g_for(Delta (gamma/0.01)^(1/4), L^2) so that the sweep-end effective
    bias is Delta (h14b's g_for assumed gamma = 0.01; asserted in the self-check).
  - "Freeze-out" (t_after = 0) is the END of the sweep (lam = +1, t = 2/gamma), as in h14b. A run is walled if it is not
    single-domain there; T = first cadence time (max(2, t17/60)) it is single-domain, right-censored at its last observation.
  - Ratio exponent q: slope of ln S50 against ln(D_eff/D_mol) at fixed l/w, least squares over D_eff = 8, 32, 64 (R8, V32,
    V64 cells), bootstrap over runs. Length exponent p: slope of ln S50 against ln(l/w) at fixed D_eff.
  - Molecular reference (no flow, D = D_mol = 1, same box, t17 with the case's D_eff): J32 (L 128), J64 (L 181), K32 (L 355).
  - A quantile that is undefined (not reached within the hold) is "above the censoring floor" (longest observation among
    walled runs / t17): a band test fails if the floor is >= the upper edge, else UNDECIDED; an "at least x" test passes if the
    floor >= x.
